# PulseTimer — список изменений для RuStore

Документ описывает изменения между двумя публикуемыми сборками и подготовлен для
модераторов RuStore. Речь только о пользовательских и значимых внутренних
изменениях; мелкий рефакторинг опущен.

- **Предыдущая сборка (1.0):** `e27dc05` — 02.10.2026 21:47:46
- **Текущая сборка (1.1):** `c3838a9` — 11.10.2026 15:48:52

| Параметр | 1.0 | 1.1 |
| --- | --- | --- |
| versionName | 1.0 | 1.1 |
| versionCode | 1 | 2 |
| minSdk (Android) | 28 (Android 9) | 28 (Android 9) |
| targetSdk | 36 | 36 |
| Разрешения | без изменений | без изменений |
| Интернет (`INTERNET`) | нет | нет |
| Резервное копирование (`allowBackup`) | `false` | `false` |

**Состав разрешений не менялся:** `FOREGROUND_SERVICE`,
`FOREGROUND_SERVICE_SPECIAL_USE`, `WAKE_LOCK`, `VIBRATE`, `POST_NOTIFICATIONS`.
Новых разрешений не добавлено, доступ в интернет отсутствует, данные хранятся
только локально (Room/SQLite).

## 1. Детальная история тренировок — новое

**Что увидит пользователь**

- В историю теперь сохраняется **разбор по каждому интервалу**: план и факт,
  а также отметка «пропущен» (если интервал пропущен кнопкой «Пропустить»).
- Тап по записи в `Настройки → История тренировок` открывает новый экран
  **«Детали тренировки»** со сводкой (плановая/фактическая длительность,
  «интервалов пройдено N из M») и построчным списком интервалов.
- Оборванные сессии тоже видны: указано, на каком интервале сессия прервалась и
  что она остановлена системой (а не пользователем).
- Можно удалить **отдельную запись** (с анимацией карточки) и **очистить всю
  историю** с диалогом подтверждения.

**Что изменилось внутри**

- Новая таблица `session_interval_logs` (сущность `SessionIntervalLogEntity`):
  `sessionLogId`, `name`, `iconEmoji`, `colorHex`, снимок `plannedSeconds` на
  момент старта, `actualSeconds`, `orderIndex`, `wasSkipped`; внешний ключ на
  `session_logs` с `ON DELETE CASCADE` и индекс.
- Новые поля `SessionLogEntity`: `plannedDurationSeconds`, `completedIntervals`,
  `totalIntervals`, `lastIntervalIndex`, `interrupted`.
- Новый экран `SessionDetailScreen.kt` и маршрут `Screen.SessionDetail`
  (`session_detail/{logId}`).
- Новые методы DAO `TimerDao`: `insertSessionIntervalLogs`,
  `updateSessionIntervalLog`, `getSessionIntervalLogsBySessionId`,
  `getAllSessionIntervalLogs`, `finalizeSessionLog`, `updateSessionProgress`,
  `deleteSessionLogById`, `clearAllSessionLogs`.
- Во `TimerViewModel`: `sessionIntervalLogs(sessionLogId)`, `clearSessionHistory()`.
- **Миграция БД `3 → 4`** (`AppDatabase.MIGRATION_3_4`): реальные `ALTER TABLE`,
  значения по умолчанию совпадают с объявлениями сущностей — обновление 1.0 → 1.1
  **не теряет** шаблоны, историю и настройки.

## 2. Ручной порядок тренировок — новое

- На карточке тренировки появились **стрелки ↑ / ↓** для перестановки.
- Новое поле `TemplateEntity.sortOrder`, сортировка `ORDER BY sortOrder DESC, id ASC`;
  методы DAO `nextSortOrder()`, `insertTemplateWithNextSortOrder()`,
  `reorderTemplates()`; во `TimerViewModel` — `moveTemplate()`.
- Миграция `3→4` нормализует `sortOrder` так, чтобы существующий порядок совпал с
  прежним `createdAt DESC` (без оконных функций — для совместимости со SQLite на
  Android 9).
- Новые и предзаполненные тренировки («Табата», «Круговая») встают первой, как и
  раньше.

---

## 3. Дублирование интервала в один тап — новое

- На карточке интервала — иконка **«Дублировать интервал»**
  (`Icons.Default.ContentCopy`).
- Копия создаётся **одной транзакцией** (`insertIntervalCopy`) и встаёт **строго
  под оригиналом**, даже если оригинал последний: `orderIndex` ниже оригинала
  сдвигаются на 1 (`IntervalOrdering.shiftOrderIndexesForCopy`), номера
  нормализуются в `0..n-1`.
- Копия появляется **с анимацией** (scale/alpha), лента сама прокручивается к ней;
  при уходе с экрана флаг анимации сбрасывается.
- Имя копии не наращивается: остаётся «X (копия)», а не «X (копия) (копия)».
- Во `TimerViewModel`: `duplicateInterval()`, `recentlyDuplicatedIntervalId`,
  `clearRecentlyDuplicatedInterval()`.

## 4. Интерактивное обучение (coach marks) — новое, крупнейшее изменение

Новый пакет `com.pulsetimer.ui.tutorial` (4 новых файла, ~1700 строк):

- `CoachMarkOverlay.kt` — слой с «дыркой»-подсветкой цели, подсказкой, кнопками
  «Назад / Далее / Пропустить», спиннером подготовки.
- `TutorialController.kt` — управление туром: подготовка шага, переходы на другой
  экран «нажатием» за пользователя, прокрутка/раскрытие, доступность «Назад».
- `TutorialSteps.kt` — тексты шагов, сквозной тур `guidedTour()` и наборы
  `SETTINGS_SCREEN`, `EDITOR_SCREEN`, `EXECUTION_SCREEN`.
- `TutorialTargets.kt` — ключи целей, `TutorialTargetRegistry`, модификатор
  `Modifier.tutorialTarget`.

**Поведение**

- После онбординга запускается **сквозной тур**: главный экран → редактор →
  настройки → идущая тренировка, с автопрокруткой, раскрытием групп настроек и
  «нажатием» нужных кнопок.
- Подсказки для экранов, которых тур не коснулся, показываются **при первом заходе**.
- Демонстрационную тренировку тур **запускает и завершает сам** — по окончании
  обучения отсчёт не остаётся идти, запись попадает в историю; «Пропустить» или
  системный «Назад» тоже завершают запущенную туром тренировку.
- Повторный запуск: **`Настройки → Справка → Интерактивное обучение`** — сбрасывает
  флаги и перезапускает обучение целиком.
- Тур переживает смену конфигурации: у `MainActivity` добавлен
  `android:configChanges="orientation|screenSize|screenLayout|smallestScreenSize|keyboardHidden|density|uiMode"`;
  системный «Назад» закрывает обучение, а не приложение.
- Слой обучения вынесен в `MainActivity` поверх графа навигации.

**Новые настройки в `AppSettings` (SharedPreferences):** `tutorialCompleted`,
`settingsTutorialCompleted`, `editorTutorialCompleted`, `executionTutorialCompleted`,
`tutorialRequested`.

**Интеграция по экранам:** `MainScreen`, `SettingsScreen`, `EditorScreen`,
`ExecutionScreen` регистрируют цели, планы показа и действия (в `MainScreen` тур
стартует только после загрузки списка тренировок).

## 5. Прочие доработки интерфейса

- **Главный экран:** цели обучения; действия карточки (стрелки порядка, карандаш,
  корзина); Snackbar «нет интервалов» с кнопкой «Редактировать».
- **Настройки:** новая группа **«Справка»** (обучение + юридические документы);
  раздел истории с карточками записей, переход в детали, подтверждение очистки
  истории; прокрутка к секциям для обучения.
- **Редактор:** кнопка дублирования, входная анимация копии, автоскролл к копии.
- **Экран тренировки:** интеграция обучения, подсказка о свайпе.

## 6. Сервис и запись данных

- `TimerService` переработан: введены `persistSessionStart()`, `finalizeSession()`,
  `persistCurrentInterval(wasSkipped)`, `persistIntervalResult()`,
  `finalizeAbandonedSession()`.
- Строки интервалов создаются на старте сессии и обновляются по ходу; прогресс
  сохраняется, чтобы не терялся при обрыве; остановка через `ACTION_STOP` или
  внешний `stopService` помечается как прерванная системой (`interrupted = true`).

## Кратко для модерации

Пользовательские нововведения релиза **1.1**:

1. **Детальная история тренировок** — разбор по интервалам (план/факт/пропуски),
   удаление отдельной записи и очистка истории.
2. **Ручной порядок тренировок** — перестановка стрелками ↑/↓.
3. **Дублирование интервала в один тап** — копия под оригиналом, с анимацией.
4. **Интерактивное обучение (coach marks)** на всех экранах с повторным запуском из
   настроек.

Остальные изменения — внутренние (сервис, миграция БД `3 → 4`, тесты, подпись
релиза, документация). **Новых разрешений не запрашивается, доступа в интернет нет,
резервное копирование отключено, все данные остаются на устройстве.**
